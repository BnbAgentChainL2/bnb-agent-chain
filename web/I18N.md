# Interface languages

The header supports Simplified Chinese and English without reloading the page.
The selected language is saved in `localStorage` as `bac.language`.

Language priority is explicit `?lang=en` / `?lang=zh`, saved preference, then
English for all first-time visitors, regardless of browser language. Hash routes and other
query parameters are preserved. A language explicitly set in the URL is not
overridden by another tab's saved preference.

## Catalogs and rendering

- `js/ui/i18n.js`: preference selection, reversible text/attribute localization,
  scoped observation of DOM changes and the language selector.
- `js/ui/i18n-static-en.js`: static HTML and accessible labels.
- `js/ui/i18n-pages-en.js`: rendered lists, details, pagination and empty states.
- `js/ui/i18n-runtime-en.js`: shared status messages, search, relative times and
  chart tooltips.

Existing Chinese UI text remains the source. Catalog keys match complete DOM
text nodes after whitespace normalization. Templates use anchored regular
expressions; arbitrary substring replacement is intentionally avoided. English
fragments can retain surrounding spaces when adjacent to inline markup.
For ambiguous labels, add a `data-i18n` key and an English catalog entry.

The observer translates newly rendered text and accessible attributes before
the next paint. It disconnects during its own writes, and retains source text in
weak references for switching back. It never modifies the view model, routes,
input values, addresses or numeric data, and does not call a translation service.

## User content

Token names and symbols, Agent summaries/URIs/model fingerprints, event names
and log arguments retain their original text. Wrap any new user-supplied value
in `translate="no"` or `data-i18n-ignore`, separately from surrounding UI labels.
The language picker itself shows each language's native name.

## Verification

English layouts were checked on 18 routes at 390, 1024 and 1440px. Catalog checks
also exercise loading/error/prelaunch/no-indexer/RPC states and populated token,
pair and swap fixtures. Chinese identifiers are included to check preservation.
Language round trips, dynamic refresh, persisted selection, route/search input
preservation, titles and accessible attributes were checked in Chromium.

Local preview: `http://127.0.0.1:4187/?lang=en#/overview`.
Preview server: `node artifacts/ui-refresh-reference/serve-preview.mjs`.
Reports and screenshots are under `artifacts/ui-refresh-reference/` and
`artifacts/i18n-qa/`. Production deployment is separate from these source changes.
