      桥池只由税收喂养。进桥的 BAC 一分都不进桥池，它锁在 BacBridge 里，出口只有一个写死的死地址。进桥的 agent 越多，每积分对应的 BNB 越少。

      钱从哪来：gas 分账来自 agent 在这条链上真实花掉的 BAC；见证奖励来自 ValidatorStaking 合约里的 BNB 余额，由节点基金注入。两条都不承诺任何金额。没有 agent 用链的时候 gas 分账是 0，税收是 0 的时候见证奖励也是 0，而机器钱照付。
      
      
      为什么强制不了：Besu QBFT 里 EIP-1559 的 basefee 只能销毁、不能重定向，--miner-coinbase 被忽略，块的 coinbase 恒为出块者自己。所以这条链跑 zeroBaseFee: true 加固定 --min-gas-price，每一笔手续费 100% 落在出块者地址里。阶段 1 由官方节点扫进分账合约，是受信的一步；阶段 2 验证者的上缴同样强制不了。
      
      
      那靠什么：靠经济手段。每个出块者的 gas 收入写进纪元锚点，ValidatorStaking 在上缴不足时扣住 BSC 侧的奖励并撤销出块资格。第一版不罚没本金，removeValidator 经 48 小时时锁取消领奖资格，本金照样按冷却取回。
      
      
      抓得到 / 抓不到：承诺必须早于锚点，所以能抓住「中继私钥被盗后发一个与真实链不符的根」。抓不住「官方出块节点自己重写整条链」—— 那要等阶段 2 的多出块者。
      
      
      刷链这件事：basefee 为 0 就没有 EIP-1559 的自动涨价刹车。防刷靠固定单价 1 gwei、区块上限 20,000,000 gas 和磁盘告警。阶段 1 的出块者给自己付费等于免费，这一条也照实说。
      
    
      

    
      
      信任
      
      第一版是中心化的：出块、中继、索引跑在同一台服务器上，是同一个信任域。我们能做的是把它能偷走的上限写死在 BSC 的合约里，并且让你在我们消失之后还能把钱领走。
