# 评审：「这像不像一条真链的浏览器」

日期：2026-09-22　　评审对象：`artifacts/design-options/explorer/{explorer,console,hybrid}/`
只看一件事：把 BscScan / Blockscout 摆在旁边，这三个壳哪个更像一个区块浏览器，而不是一份文档或一块运维大屏。

评的八条：搜索在不在、显不显眼、按下去有没有反应；有没有常驻的链状态条；最新区块 / 最新交易在不在用户找它的位置；行点进去有没有详情页、字段全不全；有没有真图表；有没有翻页；导航是浏览器导航还是文档目录；首屏有没有链上数据。

---

## 分数

| 壳 | 分 | 一句话 |
|---|---|---|
| **hybrid** | **8.5** | 唯一一个有真详情页、真 URL、真常驻状态条的。结构就是 BscScan 的结构。 |
| explorer | 6.5 | 搜索和图表做得最好，但 6 个导航里 3 个只是锚点，详情是抽屉，离开首页链状态条就没了。 |
| console | 4.5 | 顶栏很好。但它是一块运维大屏：一整页、没有列表页、全是抽屉、首屏左三分之一是日志。 |

---

## hybrid —— 8.5

**对的地方**

- `<header class="shell">` 里同时装着品牌、搜索框、NODE/RELAY/INDEX 灯、HEAD、6 项导航、和 8 格 `.sstrip` 链状态条，CSS 是 `position:sticky;top:0`。也就是说：**不管你在哪一页、滚到哪里，搜索框和链状态条都在**。三个壳里只有它做到了。BscScan 就是这样。
- 有真路由：`#/block/1234566`、`#/tx/0x2cd6…`、`#/agent/17`、`#/search/1234560`，每个还改 `document.title`。区块详情能发给别人，这是"真浏览器"和"演示页"的分界线。
- 区块详情页是整页，不是抽屉：面包屑 `概览 › 区块 › #1,234,566`、右上角 `‹ 上一块 / 下一块 ›`、区块头 13 个字段（含 状态根 / extraData / 区块大小 / baseFee=0 的解释）、右侧「这一块的 gas 费去哪了」10/90 分账条、「见证」面板、下面挂「本块交易（1）」表。这就是 BscScan 的区块页布局。
- 交易详情页字段最全：哈希 / 状态 / 区块+确认数 / **位置（第 1 笔 / 本块共 1 笔）** / 时间 / 发起 / 目标 / 方法 / 金额 / gas 用量 / gas 单价 / 手续费 / nonce / 锚定 / input data，右边「事件日志（0）」。对得上 `03-INTERFACES.md` §3.6 的 `GET /api/tx/{hash}` 返回体。
- 交易列表的「方法」列是真签名徽章：`settle(uint64)`、`addLiquidity(uint2…)`、`swap(uint256,uint2…)`、`exit(uint256)`、`合约部署`。explorer 那边只有中文词（"发消息 / 部署合约"）。方法徽章是 BscScan 交易列表最有辨识度的一列，只有 hybrid 有。
- 翻页最完整：`« 首页 ‹ 上一页 第 n / m 页 下一页 › 末页 »` **加每页条数选择器**（`b.dataset.s`），而且区块 / 交易 / Agent 三个列表页都有。
- 首屏有两张真图表（`最近 60 块的每块交易数`、`近 30 日交易数`），另外三张在下面。三个壳里只有它把图表放进了首屏。

**要扣分的地方（按严重程度）**

1. **首屏右三分之一是那个机器人。** `<div class="ph"><span class="ph-t">NODE-01 · 机房面板</span>` 加一个 ASCII 机器人 SVG，占掉首屏 1/3 宽。BscScan 这个位置放的是交易量曲线。机器人是装饰，不是链上数据。
2. **没有合约页。** `CONTRACT_ADDRS.forEach(… h: '#/agent/' + contractMap[c].agentId)` —— 搜一个合约地址，落在部署它的 agent 页上，合约自己没有页面。但 §3.6 的 `GET /api/contracts` 明确返回 `{address,deployer,agentId,block,ts,codeSize,callCount,lastCall}`，这些字段现在一个都没地方显示。
3. **没有纪元 / 锚点页。** 状态条里写着 `<div class="ss"><i>纪元</i><b>20718</b>`，区块详情里写着「锚定 · 纪元 20718 待提交」，但 `#/epoch/20718` 不存在。`/api/epochs`、`/api/epoch/{n}`、`/api/epoch/{n}/leaves` 是这条链最独有的三个端点，一个都没有入口。
4. **搜索不能用键盘选。** `qEl.addEventListener('input', …)` 只是把结果渲染成 `.sres` 里的 `<a>`，没有 keydown，↑↓ 不动，只能回车提交。explorer 的 `suggIdx` 循环和 console 的「↑↓ 选择」提示都比它强。搜索框也没有类型筛选。
5. **区块列表缺「分账」列。** 筛选条是 `全部 / 有交易 / 空块 / >1M gas`，按 gas 量筛，不按出块者筛。这条链的区块列表最该有的一列是出块者类型（官方节点 / 验证者）和 `10 / 90` 分账徽章 —— explorer 的区块表里有，hybrid 没有。
6. **最新区块 / 最新交易在 y≈545px。** 1440×900 的笔记本上只露出两三行。上面三块（CHAIN STATUS / 24 小时 / 机房面板）压得太高，而 CHAIN STATUS 里的「链 ID 56777 / 共识 Besu QBFT」和顶栏 `nav-meta` 里的 `CHAIN 56777 / QBFT 2–3s` 是重复的。
7. 搜索结果页 `#/search/q` 的表只有「类型 / 结果 / 打开」三列，十条结果读不出区别。

## explorer —— 6.5

**对的地方**

- 搜索是三个里最像浏览器的：整条独占一行的 `#sform`，下面一排类型筛选 `全部 / 区块 / 交易 / 地址 / Agent`，带下拉联想、↑↓ 选择、回车打开，输入看不懂的东西会给一句人话：「看不懂「xxx」。可以输入：区块高度（如 1,234,567）、0x 开头的交易哈希或地址、或 agent id（如 #17）。」这句错误文案是三个壳里最可信的一处细节。
- 唯一支持**地址**搜索并给出地址视图的（`showAddress()`，官方节点 / 验证者 / agent 钱包 / agent 部署的合约都能命中）。
- 区块列表和交易列表是真列表页（`#view-blocks` / `#view-txs`），有筛选 chips（`全部出块者 / 官方节点 / 验证者`，`全部 / 合约部署 / 合约调用 / 转账 / 失败`）、有 `使用率 2.42%` 列、有 `10 / 90` 分账徽章列、有完整翻页器。**区块列表里带分账列，这一点三个壳只有它做到。**
- 「链上走势 CHARTS」三张大图最好看，尤其第三张「每日 gas 费去向（按出块者分账）」的堆叠柱，是唯一一张把 10/90 新规则画出来的图。

**要扣分的地方**

1. **离开首页就没有链状态条。** `<div class="shell page" id="view-home">` 第 70 行开始，`.sgrid`（最新区块 / 出块间隔 / TPS / GAS 单价 / 24H 交易 / 活跃 AGENT / 验证者 / 桥池余额）整块在它里面。点「区块」进列表页 —— 看 `shot-blocks.png` —— 八格状态条全部消失，只剩导航和搜索。BscScan 的 `/blocks` 页上面那条永远在。
2. **搜索框不是常驻的。** sticky 的 `<header class="top">` 里只有品牌 + 导航 + 灯 + HEAD；搜索块在它外面，往下滚就没了。`shot-validators.png` 里已经看不见搜索框。
3. **6 个导航里 3 个是假页。** `<a href="#agents">Agent</a>`、`<a href="#treasury">金库</a>`、`<a href="#validators">验证者</a>` 都是锚点，`route()` 走 `el.scrollIntoView()` 这条分支，只是在同一张 4300px 长的首页里滚动。导航看着像浏览器导航，行为是文档目录。
4. **详情是抽屉，没有 URL。** `showBlock()` / `showTx()` / `showAgent()` 只开右侧 drawer，`route()` 里第一件事还是 `closeDrawer()`。区块 #1,234,567 这一页发不出去。字段本身是够的（含 basefee=0 的解释、10/90 分账条），可惜不可寻址。
5. **状态条正下方是一条文档窄条。** `<section class="xstrip">` 里三段：「是什么 / 谁能发交易 / 人能做什么」加一个「验证者规则 →」。这是首屏第二黄金位，BscScan 这里放交易量图。三段介绍文字应该在页脚或者一个「关于」页。
6. 首屏第三列是 `tail -f /bac/actions` 日志，把「最新交易」挤成了中间一列的窄表。
7. Agent 目录（42 个）是卡片瀑布，没有翻页也没有表格视图。

## console —— 4.5

**对的地方**

- 顶栏 `<header class="rail">` 是三个里信息最密的常驻条：搜索 + **10 格**状态（比 hybrid 多了「连接节点 5 / txpool 3」和「下一个锚点 03:12:41」）+ 导航，`position:sticky`。txpool 深度和锚点倒计时是"这条链现在是活的"最直接的两个数。
- 搜索下拉最好用：分组结果 + 头部提示「2 个结果　回车打开第一个　↑↓ 选择」+ 右侧 `/` 快捷键徽章，输入 `1234560` 同时给出「区块 #1,234,560 高度存在」和「交易 3 笔在 #1,234,560 里 打开区块」。
- 「纪元与锚点」面板是三个壳里独有的：`20716 FINAL / 20717 POSTED · 挑战中 / 20718 进行中` 分段时间轴、一致见证人 2/2、下一个锚点倒计时、退出释放档位 350bps。
- 最新区块面板自带页内翻页 `‹ 上一页 | 下一页 ›` 和范围标签 `第 1 页 · #1,234,554 – #1,234,567`。

**要扣分的地方**

1. **首屏左三分之一是日志。** `tail -f /bac/actions` 那一栏，从首屏顶一直铺到底。BscScan 的左栏是 Latest Blocks。这一个决定就把整页从"浏览器"推成了"运维大屏"。
2. **没有区块列表页，也没有交易列表页。** 导航 `<a href="#blocks">区块</a>` / `<a href="#txs">交易</a>` 全是 `href="#xxx"` 锚点，8 个导航项指向同一张 3700px 长页的 8 个段落。面板右上的「查看全部 ↗」也是 `href="#blocks"` —— 点了只是滚回上面那块面板。
3. **全部详情都是抽屉，没有路由。** `console.js` 里根本没有 `hashchange` 监听，`openDrawer()` 是唯一的详情入口。区块 / 交易 / agent / 地址 / 节点，五种详情，零个 URL。
4. **首页两张主表都缺手续费列。** 「最新区块」的列是 `区块 / 时间 / 交易 / gas 用量 / 占比 / 出块者 / 纪元`，「最新交易」的列是 `交易哈希 / 发起 / 目标 / gas / 状态`。手续费是这条链 10/90 分账的计价单位，两张表都不显示它。hybrid 和 explorer 的对应表都有「手续费」列。
5. 六个圆环仪表盘（66.3 / 2.40 / 350 / 83.3 / 87.1 / 100）是大屏语汇。浏览器上这些数应该是表格里的一行字。
6. 翻页只有首页面板的 `上一页 / 下一页`，没有首页 / 末页 / 第 n 页 / 每页条数。

## 结论

**赢家：hybrid。**

理由只有一条：它是唯一一个"点一行 → 进一个有 URL 的详情页 → 面包屑能退回去 → 顶上搜索框和链状态条一直在"的壳。这套路径就是 BscScan 的路径，其余两个壳在这条路径上都有断口 —— explorer 断在"详情没有 URL、列表页没有状态条"，console 断在"根本没有列表页"。

explorer 的搜索、图表、区块列表的分账列，console 的纪元面板、搜索下拉、txpool 状态格，都应该原样搬到 hybrid 上。

### hybrid 还必须改的（按顺序）

1. 首屏右三分之一的「NODE-01 · 机房面板」机器人换成交易量 / gas 图，机器人挪到验证者页。
2. 加 `#/contract/0x…`，读 `GET /api/contracts` 的 `codeSize / callCount / lastCall / deployer`；现在搜合约地址会落到部署者的 agent 页。
3. 加 `#/epochs` 和 `#/epoch/{n}`，把 `/api/epoch/{n}/leaves` 和 `proposer_income_root / gas_fees / gas_remitted / gas_gap` 摆出来。这是这条链最独有的数据，现在一个入口都没有。
4. 搜索框补类型筛选 chips 和 ↑↓ 键盘选择；`.sres` 现在没有 keydown。
5. 区块列表的筛选换成「全部出块者 / 官方节点 / 验证者」，并加一列 `10 / 90` 分账徽章（现在的 `全部 / 有交易 / 空块 / >1M gas` 没有回答"这块是谁出的、钱怎么分的"）。
6. 概览页上面三块压到 ~180px 高，让「最新区块 / 最新交易」在 1440×900 上能露出 8 行以上；CHAIN STATUS 里的「链 ID / 共识」和顶栏 `nav-meta` 重复，删一份。
7. `#/search/q` 结果表补「区块 / 时间」两列。
8. 交易列表补相对时间列，和区块列表的「22:49:31 / 刚刚」两行式保持一致。

### 从输的两个壳上移植

从 **explorer**：
- 整条独占一行的 `#sform` + `#scope` 类型 chips + `#sugg` 键盘选择 + `searchError()` 那句错误文案。
- 区块表的 `使用率 %` 列和每行的 `10 / 90` 分账徽章，以及 `全部出块者 / 官方节点 / 验证者` chips。
- 「链上走势」三张大图，特别是第三张「每日 gas 费去向（按出块者分账）」的堆叠柱 —— 唯一把新规则画出来的图。
- 详情面板头上的来源行 `BLOCK · GET /api/block/1234567`。

从 **console**：
- 「纪元与锚点」整块：`20716 FINAL / 20717 POSTED · 挑战中 / 20718 进行中` 时间轴 + 一致见证人 2/2 + 下一个锚点倒计时。
- 搜索下拉的分组头「N 个结果　回车打开第一个　↑↓ 选择」和 `/` 快捷键徽章。
- 状态条补两格：「连接节点 / txpool」和「下一个锚点」。
- 首页「最新区块」面板头上的行内翻页和 `第 1 页 · #1,234,554 – #1,234,567` 范围标签。
