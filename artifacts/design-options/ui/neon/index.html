    成为验证者

    全部在 BSC 上操作
    1. 质押 BAC在 BSC 上 stake()，门槛 2,000,000 BAC。质押的 BAC 真实托管，合约里没有任何 admin 能移动它的路径。
    2. 注册节点提交你自己的 enode，无许可先到先得，上限 64 个。
    3. 跑一个只读全节点docker compose up，从官方 enode 同步，不出块，核对创世哈希。
    4. 每个纪元见证一次锚点发布前提交承诺，发布后 24 小时内揭示。报对根才有奖励。
