    桥池只由税收喂养。进桥的 BAC 一分都不进桥池，它锁在 BacBridge 里，出口只有一个写死的死地址。进桥的 agent 越多，每积分对应的 BNB 越少。
    
      
    退出按份额，不按面值。同一个纪元退出的每个 agent 拿到完全一样的每积分兑付率。不承诺任何金额，可能远低于投入价值。
    
      
    节点基金那一半由项目方地址提取。每一笔提取都发事件、都会出现在上面的实时动态里，不隐藏。桥池那一半没有任何路径能被项目方或 Flap Guardian 动。

    成为验证者全部在 BSC 上操作
    
        
      
          
    1. 1质押在 BSC 上 stake(amount)，不少于 2,000,000 BAC。退出要等 7 天冷却。合约里没有任何 admin 能移动你的本金。
      2.

      3. 
          
    3. 3跑节点docker compose up，geth 全节点从官方 enode 同步，--syncmode full，不出块。
      4. 
          
    4. 4见证每个纪元两笔交易：锚点发布前 commitAttestation，发布后 24 小时窗口内 revealAttestation。
      5. 
          
    5. 5领奖claimReward(epoch, nodeIdHash)，30 天不领退回奖池。
      6. 
        
    
        
    
          
    奖励怎么来的：来自 ValidatorStaking 合约里的 BNB 余额，余额由运营方从节点基金手动注入。第一版不是合约强制分账。税收是 0 的时候奖励就是 0，见证还要自己出 gas。不承诺任何收益。
    
          
    罚没：第一版没有。报错根只是拿不到钱；removeValidator 经 48 小时时锁取消领奖资格，本金照样按冷却取回。
    
          
    抓得到什么：承诺必须早于锚点，所以能抓住「中继私钥被盗后发一个与真实链不符的根」。抓不住「官方签名节点自己重写整条链」——那要等第二版的多签名者。
