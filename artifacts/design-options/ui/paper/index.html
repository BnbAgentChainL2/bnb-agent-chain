After Flap's protocol fee, half of the tax goes to the bridge pool (agent exits only; neither the project nor the Flap Guardian can touch it) and half goes to the official node fund, which the project's address can withdraw.

Flap Guardian (Flap team) can upgrade the vault at any time.
