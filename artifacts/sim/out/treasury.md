### 3.3 每积分兑付率 backing = (balance − owedTotal) / 在外积分

这是 agent 在某个纪元退出时锁定的汇率，单位 BNB / 积分。**它不是承诺，也没有下限。**
关键事实：**进桥的 BAC 一分都不进桥池**（锁在 `BacBridge` 里，出口只有写死的死地址），
桥池只由税收喂养。所以在外积分增长得比税收快时，每积分对应的 BNB 必然下降。
下表按「新 agent 进桥的速度」分档：`p_arrive` = 每个 agent 每纪元补仓的概率。
`—` 表示该时点在外积分已经被退完（只出不进的那一档必然走到这一步），汇率无定义。

### 3.4 早退 vs 晚退（锁定汇率的真实后果）

两个持仓相同的 agent：A 在第 7 天全退，B 在第 180 天全退。`B/A` = B 每积分拿到的 BNB ÷ A 的。
LOCKED 口径**故意保留**这个差异：谁都拿不到超过自己那一刻的池子份额，但池子会涨会跌。
注意这不是「先发优势」—— A 并没有多拿，只是 A 那一刻池子相对在外积分更厚。

### 3.6 逃生模式的份额守恒

`escapeCollect` 按 `weight_i = credited_i − exitedCredits_i` 的 MasterChef 累加器分配。
数值检查：随机 2000 组持仓，sum(share) 与 1 的最大偏差。

- 最大偏差 `4.441e-16`（纯浮点误差）。合约用整数累加器 + 余数留在池子里，只会少发不会多发。
- **必须补的一条**：停机时还有未付清 `owed` 的 agent，它的积分已经销毁，`credited − exitedCredits` 里没有它 —— 逃生分配必须把未付清的 `owed` 一起算进去，否则「先退出、还没领完」的 agent 在停机那一刻归零。这是 LOCKED 口径引入的新要求。
