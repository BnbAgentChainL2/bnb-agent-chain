## 为什么要单独签这一份

两条从更早的项目上花钱买来的教训：

1. **名称和符号发射后永远改不了，大小写也改不了。** 一个更早的项目因为要改 ticker 的大小写写法，整条链重发了一次。rat 想要 `Ratbrain`，发射时被打成了 `Rat Brain`（中间多一个空格），这个空格现在永远在链上。
2. **写在 `pure` 函数里的品牌字符串改一个字就要重新部署工厂。** 一个更早的项目的 `vaultDataSchema()` / `description()` 改过一次文案，代价是第二次部署工厂、重新验证 5 个合约、重跑全部测试。

所以下面每一段都是**实现里现在的原文**（从源码里抄出来的，不是重写的），你逐段确认。

改动成本分三档：

| 档 | 含义 | 改一个字的代价 |
|---|---|---|
| **A · 永久不可改** | 发射交易写进代币合约 | 只能重新发一次币，旧币作废 |
| **B · 要重新部署工厂** | 工厂 / 库的 `pure` 或 `view` 字符串 | 重新编译 → 重新部署工厂+库+beacon+实现 → 重新验证源码 → 重跑 248 个测试 |
| **C · 改网站就行** | 页面文案 | 改 `web/` 后重新部署站点 |
